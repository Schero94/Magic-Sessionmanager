Strapi 5 plugin

See who is signed in. End access in one click.

Magic Session Manager records every sign-in of your app's users (Users & Permissions) as a session. Admins see which sessions are Active, Idle or Ended, end them, block users, and decide how long the history is kept.

Features

One vocabulary on every screen. A session is Active (open, used within the inactivity timeout), Idle (open, unused for longer) or Ended. An ended session shows its end reason: Logged out, Timed out, Expired, Ended manually, User blocked or Reason not recorded.

End

The session stops working. The record stays in the history.

Delete record

The record leaves history, statistics and exports. An open session also ends, and its token stays revoked.

Block

The user cannot sign in, and all open sessions end. Unblock allows sign-in again.

A user is Online when at least one of their sessions is Active. The dashboard, the widget and the user panel use this one rule.

Sessions dashboard

Main menu › Session Manager. Header links Analytics and Settings, and an Export menu (CSV or JSON, with an End reason column and no tokens). Four stat cards that filter the list, search by user, email, IP or device, Status and End reason filters, and the row actions View details, End session and More actions › Delete record. Filters and search live in the URL. Below 768 px the table becomes a card list.

Session details

A sentence that says why the session is in its state, then user, session times, device, location and security score. Look up location runs only when you click it. Technical details hold the record ID and the raw user agent. End session asks for confirmation.

Sessions panel on a user

In the Content Manager edit view of a Users & Permissions user: Online or Not online, the number of open sessions and the last activity, End all sessions and Block user with confirmation, the open sessions, and Show all sessions, which opens the dashboard filtered by the user's email.

Online users widget

On the Strapi homepage (Strapi 5.13 and later): Online users out of all registered users, Active sessions, Idle sessions and Blocked users, refreshed every 30 seconds.

Configuration

Settings › Session Manager › Configuration with five tabs: Sessions, Login protection, Location data, Alerts, and Data and retention. Each tab is a deep link (?tab=). Save and Discard changes sit in the header, and leaving with unsaved changes asks first.

Analytics and License

Analytics shows all and active sessions, sign-ins in the last 24 hours and 7 days, sessions by device and browser, and the average session length. License shows whether an optional key is stored and valid; every feature works without one.

Install

  1. Install the package.

    Terminal
    npm install strapi-plugin-magic-sessionmanager

  2. Enable the plugin.

    config/plugins.ts
    export default () => ({
  'magic-sessionmanager': {
    enabled: true,
  },
});

  3. Set the token encryption key. Production startup fails without it.

    Terminal
    node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
# add the output to .env as SESSION_ENCRYPTION_KEY="..."

  4. Rebuild the admin and start Strapi.

    Terminal
    npm run build
npm run develop

Open Session Manager in the main menu. Super Admins have access automatically. For other admin roles, grant Plugins › Session Manager › Access the Session Manager plugin under Settings › Administration Panel › Roles.

Both Users & Permissions modes work: with jwtManagement: 'refresh' Strapi issues and revokes native sessions and the plugin adds device, IP and location history; with 'legacy-support' the plugin keeps its own session records. The plugin never changes the host's authentication configuration.

Configuration

Static defaults go in config/plugins.ts with time values in milliseconds. Values saved on the Configuration page are stored in the database in minutes, seconds or days and override the static config. Other server processes apply saved changes within 30 seconds.

config/plugins.ts
export default () => ({
  'magic-sessionmanager': {
    enabled: true,
    config: {
      inactivityTimeout: 15 * 60 * 1000, // ms
      lastSeenRateLimit: 30 * 1000,      // ms
      cleanupInterval: 30 * 60 * 1000,   // ms
      maxSessionAgeDays: 30,
      retentionDays: 90,                 // -1 keeps ended sessions forever
      geoIpProvider: 'auto',             // auto | local-mmdb | ipapi | disabled
      geoLookupFailureMode: 'auto',      // auto | allow | block
    },
  },
});

Retention is checked once a day, the first time about 24 hours after the server starts. It deletes records of ended sessions only; open sessions are never deleted by retention. Delete ended sessions on the same tab removes the records of all ended sessions of all users at once. The idle check ends idle sessions as Timed out and deletes nothing.

Environment variables: SESSION_ENCRYPTION_KEY, MAGIC_SESSIONMANAGER_GEOIP_DATABASE (local MaxMind database), MAXMIND_ACCOUNT_ID and MAXMIND_LICENSE_KEY (database updates; they take precedence over stored credentials). The full reference, including Advanced settings and email templates, is in the README.

API and permissions

Content API routes live under /api/magic-sessionmanager, require a Users & Permissions JWT, act on the caller's own sessions only and are rate-limited (10 writes and 120 reads per minute by default, then 429 with Retry-After).

Content API
Method Path Purpose
GET /my-sessions Own sessions, current one first (up to 200)
GET /current-session The session of the current token
GET /user/:userId/sessions Own sessions by user ID; 403 for another user
POST /logout End the current session (Logged out)
POST /logout-all End all own sessions
POST /logout-others End all own sessions except the current one
DELETE /my-sessions/:sessionId End one other own session (Ended manually)

Admin routes live under /magic-sessionmanager in the Strapi admin API. Each one requires an authenticated admin and the permission plugin::magic-sessionmanager.access, which also controls the menu link, settings links, widget and user panel.

Admin API
Method Path Admin action
GET /sessions, /sessions/active Dashboard, widget, Analytics (latest 1,000 sessions)
GET /user/:userId/sessions Sessions panel
POST /sessions/:sessionId/terminate End session
DELETE /sessions/:sessionId Delete record
POST /sessions/clean-inactive Delete ended sessions
POST /user/:userId/terminate-all End all sessions
POST /user/:userId/toggle-block Block user / Unblock user; send { "blocked": true | false }
GET /users/stats Widget totals
GET /geolocation/:ipAddress Look up location
GET, PUT, POST /geoip/status, /geoip/credentials, /geoip/update GeoIP database status, MaxMind credentials, database update
GET, PUT /settings Configuration
GET /license/status License page

Requests with an ended session receive 401 and the header X-Session-Terminated-Reason (logout, manual, idle, expired or blocked). The optional route policy plugin::magic-sessionmanager.session-required adds an explicit check to your own routes. Response shapes and error codes are in the README.

Security and privacy

Production requirement: set SESSION_ENCRYPTION_KEY before starting Strapi with NODE_ENV=production; startup fails without it. Keep the key stable, because changing it makes stored tokens unreadable.

Session security

Stored tokens are encrypted with AES-256-GCM and never returned by any route or export. Ended, expired and revoked sessions and blocked users are rejected on every Content API request. A password reset ends all older sessions of the user.

Ownership

Content API routes only return or end the caller's own sessions. A foreign session ID answers exactly like a missing one, so IDs cannot be probed.

Login protection

Applies to new sign-ins only: a temporary 15-minute IP lockout after failed sign-ins (429), rejection of VPN, proxy, threat or low-score sign-ins (403), and country rules (403). Refused sign-ins are not recorded, and user accounts are never blocked by the lockout.

Location data and privacy

IP location lookup is on by default with the Automatic provider, which can send IP addresses to ipapi.co. Choose the local MaxMind database or turn the lookup off to keep IP addresses on your server. The details dialog looks up a location only when you click the button.

Retention

Session records hold IP addresses, user agents and location. Set Keep ended sessions for to match your retention policy; Delete record and Delete ended sessions remove history on demand.

Secrets

The MaxMind license key is stored in the plugin store and never sent back to the browser. Webhook URLs accept Discord and Slack hosts only; treat them as secrets.

Strapi administrator sessions are out of scope. Report security issues through GitHub issues without including credentials or personal data.

Releases and maintenance

4.8.0: not accepted

Published before its acceptance gates closed. Known defects, all fixed on the redesign branch:

  • The Session details dialog has no accessible name.
  • Settings field hints, including the GeoIP privacy note, never render.
  • Three Settings alerts have unnamed close buttons; country chips cannot be removed with the keyboard.
  • In legacy-support mode a password reset leaves older sessions usable.
  • A failed block followed by a retry of the bodyless toggle unblocks the user.
  • The Content API rate limiter can be bypassed by varying the request path.

Accepted on the redesign branch

  • Clean install: 749 of 749 tests pass, both type checks, build, verify, verify:runtime and npm pack --dry-run.
  • Desktop and mobile browser passes for every screen on an isolated Strapi 5.61.0 host with synthetic data and outbound network blocked.
  • Strict source symmetry contract: 7 of 7 (no window.confirm, emoji, colour literals, px font sizes or custom media queries).
  • Measured: widget at 320 px with 0 px document overflow; user panel link 32 px high; document titles set by the shared page shell.
